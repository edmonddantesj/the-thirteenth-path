# 第六十八章 弯了却没有折断的秩序

里头的门关上之后，外面的空气平静得反常。

瑟琳觉得，这反倒才像这地方。

局破得那么大，本该更喧闹才对。推卸责任的声音，嚷着谁输谁赢的嘴，瞅准机会就贴上来的手。可自从扎赫划下线，说“在内区结算”之后，旧货场里头的空气反倒很快沉了下去。

这说明大家都知道，此刻谁再嚷，那话也成不了值。

陆海靠在离中庭稍远的铁柱旁，终究没忍住，嘀咕了一句。

“真够久的。”

卡埃尔简短地答。

“要是很快就完，那才更奇怪。”

陆海撇了撇嘴。

“这倒没错，可把人憋得好奇死，总得有个理由吧。”

瑟琳像是没把那话听进去，目光却一直盯着里头出入门附近和扎赫那边人的动静。

扎赫仍旧留在外面。

这出乎意料。瑟琳本以为他会跟着进去。可扎赫只把人送到门槛就停下了，选择留在外面，把哈隆、纳森、娜希拉和里头所有人重新拢进自己的视野里。

光凭这一个选择，瑟琳就有点明白这地方为什么不会塌了。局外生出的问题放进局里，局里会生出的问题再从外面压住。扎赫一次也没有完全松开那条线。

阿特尔看着这样的扎赫，静静地说。

“比想象中精巧得多。”

瑟恩立刻接上。

“这样的地方原本更可怕。”
他低声说。
“并非因为没有法才运转，而是因为看起来不像法，才运转得更久。”

瑟琳听了，极细微地笑了。这方式她不喜欢，但话是对的。

哈隆站在离扎赫稍远的地方。

他没有跪下，也看不出要逃的意思。

那态度反倒更显眼。那是一个行为被识破、却不认为自己完全错了的人的站姿。

瑟琳认得这种人。有时比贪心的家伙更让人头疼。相信自己是对的那一方，越线的那一刻也在替自己的手开脱。

扎赫先开了口。

“哈隆。”

声音不大，四周却立刻静了。

哈隆没有低头。
只是极低地答。

“在。”

“你今天越了线。”
扎赫说。

哈隆沉默片刻，答道。

“您若认为我越了，我领。”

陆海轻轻屏住了气。

瑟琳眯起了眼。

那不是求饶。意思是他为什么那么做，这一点还没有弯。

扎赫不可能不明白这一点。

“为什么那么做。”
他问。

哈隆这次答得很快。

“我认为，哈兹兰变成集市之前，先得撑住的是秩序。”
他说。
“外乡人一旦攥住真东西、把整个局掀翻，连里头的手都可能跟着动摇——我是这么判断的。”

阿特尔的眼神极细微地变了。

瑟恩没有说话，卡埃尔连冷笑都没有。因为大家都明白，这话值得一听。

哈隆接着说。

“错的手要是先攥住真东西，哈兹兰就会失去秩序。所以我让它停下了。”

“不是停下，是拧弯了。”
瑟琳低声截断。

哈隆这才头一回看向瑟琳。

“比赛没有破。”

“昨天你也这么说。”

瑟琳说。

“说破的是比赛外面。”

“这话没错。”

“所以问题就在这儿。”

瑟琳往前走了一步。

“不在比赛里做，就算没做？那这地方不管在哪儿做什么，全都是比赛外面了。在不标值的地方做，就不用付值，不就是这个意思吗。”

哈隆没有马上回答。

看着那份沉默，瑟琳明白了。那个人不是第一次听到这话，而是头一回在这套说法行不通的地方听到。

“秩序有时得弄脏手才留得下来。”
他说。

瑟琳嗤地笑了。

“说这种话的人里，把弄脏自己手的值付到底的家伙，我可没见过几个。”

气氛薄薄地晃了一下。

可扎赫没有任那晃动留着。

“哈隆。”
他再次唤道。
“你想守住哈兹兰的秩序，这我知道。”

哈隆的眼神极细微地晃了一下。

那不是被接纳后松下来的脸。是刚刚发现自己被看透的脸。

扎赫极低地接着说。

“所以更要罚。”

这一句话让空气变了。

陆海睁大了眼，卡埃尔极细微地抬了抬下巴。瑟恩则是一副早知道这话会出来的神色。

扎赫说。

“你说要守住秩序，却替秩序做了判断——那一刻，今天在哈兹兰最先损害秩序的，也是你。”

阿特尔极低地呼出一口气。

这和帝国的审批结构相似，同时又全然不同。

为了秩序动用例外。可那例外由谁审批，最终成了关键。扎赫此刻正是在那一点上打哈隆。

哈隆这次没有反驳。

只是极慢地说。

“罚，我领。”

扎赫点了点头。

“从今天起一个月，”
他说。
“你不得进里头的局。”

哈隆的眼神头一回明显地晃了。

不是死，不是驱逐，也不是砍手腕那种示众。

可在这里，那或许是最痛的罚。进不了里头的局，意思是扎赫定下真值、挑选下一只手、重新立起里头秩序的那个位置，哈隆有一个月站不上去。

瑟琳明白那份罚为什么是那个样子。

这里的罚不是为了让人痛，是为了重新标值。

把哈隆赶出去，那双手知道的东西也会跟着出去。杀了更是如此。可就这么放着，下次他还会自己做判断。

所以只把他从做判断的位置上拿下一个月。手留下，只拿走权限。

瑟琳以为那是算计，随后又改了想法：其中也有不是算计的部分。

一个月就能回来。是为了让他能回来，才这样切的。

扎赫没有就此打住。

“还有你动过的复归线和赛场边缘的装置，”
他说。
“全部用你自己的手复原。”

陆海几乎是下意识地嘀咕。

“哇，那可真够受的……”

瑟恩极低地说。

“所以才是罚。”

然后补了一句。

“那是给还要再用之人的罚。”

扎赫一直看着哈隆。

“你说想守住的那个秩序，”
他说。
“这次用你自己的手重新立起来。”

哈隆好一阵没有回答。

那不是将要崩溃前的沉默。是一个人此刻才弄明白哪里最痛的沉默。

最终他极低地说。

“我领。”

和刚才说的是同一句话。

可瑟琳听来和刚才不一样。刚才说的是，若认为他越了线，他就领。现在只说，他领。

两句之间去掉的，是条件。

瑟琳看着那一幕，想。

这地方一团糟。人们给东西贴值，局总被拧弯，行骗的手也多。

可它没有完全塌掉。因为总有人最终把值重新讨回来，重新划线，让人用自己的手把自己弄乱的东西立起来。

卡埃尔低声说。

“比想象中像样。”

阿特尔答道。

“与其说像样，”
他静静地说。
“不如说是在按自己的方式运转。”

瑟琳觉得这话更对。

这里不是帝国，也不是同盟。但也并不因此就是个更胡乱运转的地方。

哈兹兰正以哈兹兰的方式，把一度弯折的秩序重新立起来。

而希昂一行在这里要带走的，恐怕也不只是金属或一艘船——这个念头这才清晰了一点。
