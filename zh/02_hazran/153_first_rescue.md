# 第一百五十三章 第一次营救

第一次营救，
比想象中更安静地开始了。

瑟拉基昂本就是一个不出大声便将人带走的世界，
所以第一次撼动那套秩序的事，
反倒不能以太大的声响开场。

侦察组与带回之手们，
分散贴到了预先定好的交替线前那一段。

卡埃尔守住封闭顺序的位置，
阿特尔守住最自然地制造错乱的位置，
韩智宇与带回之手老二守住抽离孩子的位置，
带回之手老大守住回返流向的位置。

不再多言。

已经计算得太多了，
从此刻起，各自要用自己的身体去证明。

先动的是阿特尔。

他像在模仿上方区块的节拍，
不急也不缓地走了进去。

接着，他与一台沿对齐线移动的机器，
只在极其微不足道的程度上叠了一下动线。

只够像一个失误。
只够引来收拾，而非怀疑。

就那一处小小的错位，
前排两台机器的视线偏了那么一次。

真的仅此而已。

可在瑟拉基昂这样过度整齐的世界里，
那一点便已足够。

节拍只要被微微扰动一次，
其后对齐完全锁死之前，便会留出短暂的缝隙。

卡埃尔一直在等那一刻。

他立刻朝对面那道狭窄的封闭轴转身，
精准地拖慢了预先看好的一处折叠。

不是硬生生地令它停下。
也不是将它彻底打碎。

只是把本该封闭的顺序，
拖慢了比一拍稍微少一点。

瑟拉基昂的结构，比起被完全打开，
更怕的是不能精准地封闭。

只要错位一次，
下一道折叠便会因重新计算自身，
而在瞬间留下空隙。

就在那一刻，
韩智宇与带回之手老二同时切了进去。

队列还没有完全崩塌。
可也已不是与先前相同的秩序了。

三个孩子在对齐线内，以极其微妙的不同节拍轻轻晃着。

韩智宇没有迟疑。

最先，
她用指尖抓住了那个仍未放开自身停顿的孩子的手腕。

没有用力拽。
而是极低、极快地说：

“走。”

那一句话，
孩子起初像是僵住了。

可手却不同。
手早在那句话之前，
就已顺着自外而来的力的方向跟了过来。

第二个是阿特尔选中的孩子。

那孩子没有抬头看，
视线依旧垂向下方。

带回之手老二几乎像机器一样，以短促的动作
从后方裹住了那孩子的肩。

孩子的身子瞬间僵了。

可就在那时，
阿特尔极低地说：

“别看。来。”

那句话竟奇异地奏效了。

孩子僵硬的身子
虽没有完全松开，
却至少开始把自己从上方的节拍里剥离出来。

第三个最危险。

那个原本快半拍的小孩子，
似乎已察觉错乱发生，
反倒想先动起来。

那并不只起了好作用。

孩子几乎像是奔跑般朝旁侧蹿去，
那一下，紧挨着的一道对齐线
比预定的晃得更大。

卡埃尔低声说：

“太快了。”

那句话刚落，
上方一台机器便完全转过了视线。

从此刻起，已更接近察觉，而非收拾。

韩智宇连骂都来不及，
先把身子朝那孩子那边折了过去。

那一瞬，带回之手老大从后方截断了流向。

极短地，
用身体挡住了对齐重新对上所需要的一条动线。

瑟拉基昂那边两台机器同时想重立节拍的刹那，
那道流向被折叠了半次。

那半次便已足够。

韩智宇几乎像抱住般擒住那个快的孩子，往内里拉，
带回之手老二把先前抓到的第二个孩子往后递了过去。

第一个孩子已是被拖着而非奔跑的速度，
可分明在用自己的脚跟着走。

卡埃尔没有回头。
而是一直只读着封闭的顺序。

“现在。”
他低声说。
“别往左，走中间。”

带回之手老大依言转了身。

照常理，往左侧抽离才是更自然的结构。
可正因如此，
瑟拉基昂也会先把那一侧折起。

中间狭窄而粗糙，
不显眼，
却恰好只能通过一次的路。

三个孩子彼此速度不同。

第一个孩子像在竭力不放开手地跟着，
第二个孩子用自己的脚走着，却一直强撑着不回头，
第三个孩子太快，反倒好几次险些毁了节拍。

那无序的节奏，
比想象中更让逃离变得艰难。

瑟拉基昂本就是擅长读取并控制各自不同速度的世界。
可此刻这一边，
却要把那些不同的速度硬生生往一个方向带出去。

一个孩子慢，全体便延误，
一个孩子快，对齐便破裂，
谁一僵住，后方便立刻折起。

背负着这一切，
他们仍得不停地走。

后方传来一声极低的、像警报般的声响。

并不大声喧闹。
可正因如此，更糟。

瑟拉基昂向来如此。
在完全显露之前，
先悄悄开始封闭。

卡埃尔一听见那声音便说：

“别跑。”
“只对齐速度。”

那句话精确得异乎寻常。

在这里若一味地跑，
最慢的孩子便会立刻被抛下，
最快的孩子又会再次往前蹿出，
全体崩得更快。

所以他们没有跑，
而是硬生生造出同一方向的节拍。

韩智宇不放开第一个孩子的手，
带回之手老二匀力地推着第二个孩子的肩，
带回之手老大时不时拦住第三个孩子，不让他过分领先。

终于，
折入隐藏层的最后一道拐角出现了。

直到触及那里的一刻，
也没有人觉得已经成功。

因为在瑟拉基昂，
往往就在感到几乎抵达时，封闭得最快。

可那一天，
唯独一次。

卡埃尔拖慢的折叠、
阿特尔造出的错位、
韩智宇读出的手、
还有带回之手们撑住的流向，
当真千钧一发地咬合到了一起。

当三个孩子完全跨入隐藏层内侧时，
没有人能立刻开口。

韩智宇仍没有放开手，正调着呼吸，
阿特尔为了不回头，紧紧咬着下颌，
卡埃尔到此刻才闭了一次眼，又睁开。

带回之手老大最先低声说：

“开了一个。”

那句话听上去并不像喜悦。
反倒像是在确认，一件更大的事如今才刚开始。

实际也是如此。

抽出了三个。
可瑟拉基昂依旧在上方，
其他孩子依旧留在那节奏之内，
也无从保证这一次的裂隙，下一次还能以同样的方式奏效。

尽管如此，
那一天第一次，
那三个瑟拉基昂仿佛一次也不会失手般带走的孩子，
当真被外侧的手抓住，带了回来。

那还不能称作胜利。

可分明，
这是第一次，有人被从那个世界的节拍里抽了出来。
