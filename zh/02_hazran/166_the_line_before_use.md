# 第一百六十六章 在称它们为战力之前

引入仿生人的第二天，
老旧楼层内侧的空气比前一天更安静了。

可那份安静，离安定还差得远。

谁都不敢贸然靠近，
谁也说不出要把它们彻底赶走。

仿佛所有人，
都还是一副连该怎么称呼那些东西都尚未定下的脸。

哈兹兰来的人更是露骨。

朝着仿生人所在的区划，
他们干脆把动线绕开了一大圈，
孩子们每次从那附近经过，
都把大人的手攥得更紧。

希昂看着这一幕，
再次感到恐惧总是比逻辑更先留在身上。

这不是补上几句说明就能立刻消散的那类反应。

就连内侧那些老旧的机器，
朝那边看时也会极短暂地停顿一下。

要说是敌意，很难。
可要说是欢迎，就更不是了。

那种反应，
更像是重新撞见了某种已经过去得太久、
久到如今连该叫它什么都已经模糊的东西。

韩智宇从早上起话就少。

并不是觉得前一天抛出的话太重了。
反倒像是还说得不够。

问题在于，没有正解。

那东西是真的空着，
还是我们想要相信它是空着，
眼下谁都没法确定地说出口。

可即便如此，‘能用’、‘不能用’、‘是工具’、‘不是’
这类话却已经开始来回飘起，
只要从那一刻起，
似乎就会有太多东西错位。

当一只外面的手再次走进那个区划时，
陆海先是尖锐地问了一句。

“今天又想干什么。”

外面的手停顿了一下。
然后极低地说。

“不能只是把它们晾在那儿。”
“对方已经在变得更快了。”

“这是最危险的话。”
韩智宇低声说。
“说是要确认，
结果就用上了。”

外面的手立刻接了下去。

“我不是说不用。”
“可对方要是先递过来，
光看着就会迟。”

韩智宇没有马上回答。

不是没有回答，
而是太轻易地往一边给出答案，
就会顺着那道缝隙滚下去。

这时希昂在旁边极低地说。

“现在连看见了什么，
都还没全定下来呢。”

那句话并不是站在谁那边的话。
可正因如此，它让所有人都停了一下。

没错。

前一天引入了仿生人，
害怕过，
不自在过，
也生过气。

可在那之后实际看见了什么，
还没有谁好好理清。

阿特尔远远站着，
看着仿生人之间站立的间隔。

瑟恩和前一天一样话少，
有一台老旧的机器在那区划入口附近来回踱步，
最终也没有走进去。

那些动作全都，
看上去像是某种判断之前的犹豫。

希昂奇怪地觉得，那反而更重要。

谁都还没有确信这一事实。
那或许是眼下最后剩下的一道安全装置。

就在那时，
一具仿生人极其细微地动了一下头。

那是在没有任何指令落下之后。
是没有谁靠近的瞬间。

陆海立刻抬起头。

“看见了？”

外面的手立即说。

“是反射动作。”

可那句话，
一听到，就让人觉得太轻易了。

韩智宇朝那边看着说。

“你们老是太快下名字。”

外面的手短短地问。

“那该说它是什么。”

韩智宇沉默了一下。

然后极其谨慎地说。

“该说不知道。”

那一句之后，
奇怪的是，谁都没能马上反驳。

不知道这话很慢。
让人憋闷。
可在此刻这个位置上，
它听起来也像是最负责任的话。

就在那时，一台老旧的机器，
第一次向内侧迈进了一步。

众人本能似地屏住了呼吸。

那台机器没有走到仿生人面前。
在中途停了下来。
然后极其缓慢地举起了一只手。

不是攻击，
不是指示，
也不是信号的，一个暧昧的高度。

那个姿势奇怪地停留得更久。

仿生人们就那么站着。
可站在最末端的那一具，视线轴
极其细微地晃了一下。

瑟恩第一次抬起了眼。
阿特尔也在那一瞬间把视线定住了。

陆海低声咕哝。

“那又是什么。”

谁都解释不了。

无法解释这一事实，
反而变得更鲜明了。

一只外面的手的光学眼极短暂地晃了一下。

那与其说是看见威胁的反应，
更接近于他原本当作前提的某个简单结构正在动摇的那一刻。

韩智宇直到看见这个，
才稍微长长地吐了口气。

然后说道。

“所以说。”
“不能随便用它们。”

这一次，瑟琳也没有马上接话。

而是把仿生人们、
老旧的机器、
哈兹兰的人们、
外面的手们，
还有希昂一行，挨个扫视了一遍。

此刻在这里，但凡有一样东西被仓促定下，
那个决定就会马上成为下一个标准——
她也是一副明白这点的脸。

过了好一阵，瑟琳才开口。

“好。”

众人都朝她看去。

“今天不再碰了。”
“现在既不是把它们留着，
也不是把它们赶走。”
“别急着给它们命名，
也别急着先定用途。”

陆海一副憋闷的样子问。

“那就一直这么晾着？”

瑟琳摇了摇头。

“不。”
“不是这么晾着，
而是现在朝着‘不喊错’的方向撑住。”

那句话奇怪地把屋里的空气稍微改变了一点。

不是因为得到了答案，
而是因为至少定下了，眼下哪些东西还不能称作答案。

这时，一只从外面急忙进来的手，一边匀着气一边说。

“上层的移动变快了。”
“引导线的间隔变了，
闭塞的节拍也变了。”

瑟拉基昂没有等。

对方已经在更快地移动了，
而这边只是这么停着不动，也不可能撑太久。

可希昂反倒因此，
觉得此刻这份缓慢的犹豫更重要了。

因为以必须变快为由，
一定会有那么一刻，先把最不该丢的东西丢掉。

瑟琳短短地说。

“好。那就再加把劲。”

陆海立刻问。

“加什么？”

瑟琳朝仿生人们所在的区划看了一眼，
又看向通往瑟拉基昂上层、那条幽暗的通道。

“计划。”
“赶在对方前面。
先定下我们到底要在哪里为止，不变得跟它们一样。”
