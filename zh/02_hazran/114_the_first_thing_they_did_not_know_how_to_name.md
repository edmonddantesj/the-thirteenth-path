# 第一百一十四章 他们第一次抓住却还无法命名的东西

希昂想数时间，又作罢了。

过了一天还是过了半天，根本没法知道。船里没有太阳，也没有影子，除了人们偶尔合眼又睁开，没有别的东西能把时间分成段。

在哈兹兰有阳光。从阴影里走到阳光下，热气就会穿透衣服往上冒，靠这个就知道一天到了哪儿。

这里没有那个。

希昂莫名觉得空落落的。能数的东西又少了一样。

韩智宇又坐回了那块面板前。

从昨天起是第几次了，希昂也数过，又数丢了。

她面前放着一张写了一半的清单。那是记船况的纸，左边一栏写得满满的，只有最下面一行空着。

“想写什么又没写？”

“名字。”

希昂没能马上听懂。

韩智宇用手背敲了一下那张纸。

“故障就写故障，损伤就写损伤。这样下次再看的时候，才知道该看什么。”

“那那个呢。”

“所以才写不下去啊。”

她又看了一遍清单。附在这艘船上的东西都有名字。裂开的地方，烧过的地方，临时绑住的地方，重新搭上去的地方。全都有叫法，所以全都能下手。

只有那个，没有叫法。

“没名字就修不了？”
希昂问。

“修不了还是其次。”

韩智宇说。

“没法交给下一个人。”

希昂把那句话在心里放了很久。

然后，他在船里绕了一圈。顺便听了听大家都把那个叫作什么。

卡埃尔叫它那个位置。

瑟琳叫它那个。

陆海一直叫它那玩意儿，有一回说成哈兹兰剩下的，自己又把话尾含糊了过去。

瑟恩干脆不叫。只用手指一指方向。

阿特尔叫它那个点位。帝国的说法就那样出来了。

六个人把同一样东西叫成了六种。谁也没用同一个词，可也没有谁听不懂。

希昂反而觉得这很可怕。

看着同一样东西，叫法却全都不一样，以后就没法跟不在这里的人说明。各自用自己的话记住，各自留下不一样的东西。

他想起瑟恩以前说过的话。一起待过，却记得不一样，下次再见时，就成了从别处来的人。

希昂先去问了阿特尔。

“帝国管这种东西叫什么。”

“不叫。”

“一个叫法也没有？”

“名字由起名的一方决定。”
阿特尔说。
“在帝国，名字不是由发现的人起，而是由审批的一方起。”

希昂知道，这和哈兹兰正好相反。

哈兹兰是在发现的地方给名字。扎赫发现了那个婴儿，当场就叫她阿珂，于是那个地方成了城市。给名字的手和发现的手是同一双。

在帝国，发现的人没有这个权限。

“那那个什么时候才会有名字。”

“按帝国的方式，不会有。”
阿特尔说。
“因为要审批的人从没见过它。”

希昂把那个回答嚼了很久。

见过的人没有权限，有权限的人没见过。那么夹在中间的东西，就永远得不到名字。

希昂走到瑟琳那边。

“为什么只叫它那个。”

瑟琳没有马上回答。然后她看了希昂一眼。

“起了名字，就会去找它。”

“不能找吗？”

“找没关系。”
瑟琳说。
“名字一贴上，值就贴上了，值一贴上，就会有家伙来抢。”

希昂的呼吸微微变了。

这是在灰色地带活了很久的人嘴里说出来的话。那个人是见过有了名字的东西后来会变成什么样的。

“那就一直叫那个？”

“现在是。”

瑟琳的背离开了墙。

“不叫，也是守住它的一种办法。”

希昂把这句话也收好了。

韩智宇是因为写不出所以叫不出，瑟琳是因为叫了危险所以不叫。对着同一个地方，理由却是相反的。

卡埃尔那边连问都不用问。希昂一走近，他就先开口了。

“起了名字，手就不一样了。”

“怎么不一样。”

“知道名字的东西，人就会随手乱碰。”

希昂知道，这和昨天韩智宇说谁都别靠在那儿是同一个意思。一个人说因为不知道所以要小心，一个人说知道了反而就不小心了。

希昂看向阿珂。

阿珂坐在靠近地面的地方。脸色比昨天更白了，坐姿却没有乱。

希昂在她旁边坐下。

“你能给它起个名字吗？”

阿珂没有回答。

希昂没有问第二遍。他和阿珂一起，看着她看的那个地方。

过了很久，阿珂极低地说。

“还不行。”

“为什么。”

“现在起了名字，就到此为止了。”

那句话是什么意思，希昂只听懂了一半。

起了名字，就成了知道的东西。成了知道的东西，就会停在那里。现在那个，还属于没定下会变成什么的那一边。

可希昂听懂一半之后剩下的那一半，在别的地方。

阿珂是被给了名字的人。

哈兹兰发现阿珂、给她名字的那一天，就是这座城市成为城市的那一天。那座城市从给出名字开始，昨天关上了。

那就是说，给名字的手如今哪里都没有了。

希昂没有把这个念头告诉阿珂。

陆海在对面看着这一幕，开了口。

“在哈兹兰，标不出值的东西不卖。”

希昂回过头。

“卖不出去怎么办。”

“放在一边，就是不给它起名字。”
陆海说。
“等到有人认出它的值为止。”

“不是扔掉？”

“扔了，下一个能认出来的人就看不到了啊。”

希昂觉得这是很哈兹兰的做法。不知道值的时候，不说不是，而说还没有。

韩智宇听见了这些话。

她盯着清单上那一行空白看了很久，一个字也没往里写。只在那一行旁边划了一道短短的线。

“是空着的。”
她说。
“就跟写上‘还不知道’一样。”

希昂看着那道线。

和他昨天在金属板上划的那一道很像。

两个都不是数字，也不是名字。只是“这里有什么东西”的记号而已。

然后，希昂注意到地上那边变了。

到昨天为止，哈兹兰人都是沿着墙围坐着。现在只有那块面板前面的地上是空着的。

谁都没坐在那里。没有人赶，也没有人说。就那么一块空了出来。

韩智宇说谁都别靠在那儿，是昨天的事。可那些人不只是不靠，而是把前面整个空了出来。

那不是学来的，是本来就知道的做法。

难民那边有个孩子往那块空地上迈了一步，又被大人的手拉了回去。

拉住孩子的那只手并不急。不是因为危险才拦，而是一只知道那里现在不是能碰的地方的手。

希昂的眼睛离不开那只手。

那些人没有问名字。他们从哈兹兰来，所以早就知道没有名字的东西该怎么放着。

船体低低地响了一声，又沉了下去。

韩智宇把手拿开，说道。

“得一直看着。”

“要修吗？”

“不。看它变不变。”

她把清单折起来放进口袋。那一行空白就那么留着。

那一天，希昂什么也没能数。

时间没数成，那个也没数成，往后还剩几天也没数成。

可有一件事他知道了。

让它就那样没有名字地放着，也是放着的一种办法。和说它不存在、把它抹掉，是不一样的。

希昂想了一下，要是由自己来起，会叫它什么。

什么也想不出来。想到的每一个，都被拽向了已经知道的东西。故障，痕迹，剩下的东西。全都是比那个小的词。

所以希昂也没起。

不是因为没有词可用，而是觉得一起名字，那个就会缩到只有那个词那么大。

希昂想，阿珂刚才说的，也许就是这个意思。

哈兹兰关上了，给名字的手也一起关上了。

所以这东西如今没有任何名字，就那样一直在这艘船里。
