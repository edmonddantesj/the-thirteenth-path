# 第一百三十六章 暗路的呼吸

亲眼看见那条路真正开启，
是在那天傍晚彻底过去之后。

确切地说，
与其说是完全敞开，
不如说更近于看见它短暂地喘了一口气。

那些陈旧的机械，整个白天都不曾说一个字。
既没有否认韩智宇和阿珂所见，
也没有立刻拿出什么来展示。

那份沉默，是一种戒备。

这里在必要的时刻会把人接纳进来，
能救的就救，
也分给人各自的那一份。

可即便如此，这里也不是一个轻易把一切都摊开给人看的群体。

希昂反倒觉得，这一点很自然。

这个古老的层之所以能撑到今天，
原因之一，大概就是这种迟来的确认与缓慢的开放。

太阳完全西斜，
白日的喧嚣再次一点一点沉静下来时，
和前一天相同的那台陈旧机械，朝希昂一行走来。

这一次，它叫的不只是希昂。

韩智宇，
阿珂，
瑟恩。

还有自始至终一言不发、却一路跟来的陆海。

机械并不刻意阻拦他。
可也算不上是允许。

它只是转过身，简短地说道。

“既然看见了，就没法装作不知道了吧。”

那句话听起来不像是许可，
倒像是通知他们——又跨过了一道考验。

他们挑了古老层中人们走动相对稀少的时段，
重新走向那堵被封死的墙。

白天看时，那里不过是一面陈旧、封闭已久的金属面，
靠近了才发现，它正发出一种细微的、不同寻常的声响。

来自极深的内里，
仿佛空气被压了一下又回弹的声响。

韩智宇最先听见了它。

“不是空墙的声音。”
她低声说。

陈旧的机械没有回答，
而是把手按在墙缘几处几乎看不见的凹槽上。

那动作，连用“手”来形容都显得含糊。

既不是按压，
也不是开启，
更像是让古老的金属自己想起自己的那种动作。

于是墙面的一侧，极其细微地颤动了一下。

它并没有大开。
真的只够一个人的肩膀勉强挤过，
裂开了一道极薄的缝。

可从那道缝里渗出的空气，
已经把一切都说尽了。

它和古老层内里的空气不同。

更冷，
更干，
连金属的气味也不一样。

阿珂几乎像吐息一般低声说道。

“来来去去的气味。”

韩智宇一闻到那气味，也小声嘀咕。

“沾上外头的空气了。”

那不只是单纯“外头的空气”的意思。

既不是瑟拉基昂那擦拭得光亮的内里，
也不是这古老层里久积的气味，
而是穿过某处、又重新折返回来的金属气味。

希昂久久地望着那道缝的内里。

几乎没有光。
可那也不是一片彻底死寂之处的黑暗。

极其微弱地，
在更深的某处，一根活着的光线如躲藏般闪烁。

瑟恩低声说道。

“有信号。”
“不是固定的，
而是短暂接入又切断的方式。”

那句话，把这条路至今仍在被使用的证据，刻得更加分明。

陆海在那道窄缝前皱起了眉。

“真有啊。”
“就这么把它藏起来出入？”

陈旧的机械没有回应他的话。
而是极低地说道。

“一条被发现就得封死、
不被发现才能活下去的路。”

那句话既是在解释这条路，
听起来也像在解释这群体伸向外面的所有那些手。

不能被人看见，
却也不能死去。

希昂再一次感受了那道缝内里的空气。

就在那一刻，
他生出一个念头——若说这古老的层是保存记忆的地方，
那条路，大概更近于把意志一路运送到外面去的那一侧。

有留下来的人，
也有出去又折返回来的人。

两者都在，
这里才不会就那样凝固成一片废墟。

就在那时，
更深处的黑暗里，响起一声极短的摩擦声。

所有人同时停住了。

陆海的身体最先绷紧，
瑟恩的眼神立刻变了，
希昂也下意识地屏住了呼吸。

陈旧的机械手仍按在缝上，
极低地说道。

“别动。”

那声音里第一次，
带着一种与它在古老层中始终维持的干涩不同的紧绷。

阿珂望着缝那头的黑暗，
用几乎听不见的声音说道。

“不是从里面来的。”

希昂看向她。

阿珂没有移开视线，接着说。

“是折返回来的那一侧。”

仅凭这一句，
整片空气都变了。

这不是一处展示死路的地方。
这或许是此刻，
一只刚从外面归来的、别的手
触到这道门槛的瞬间。

陈旧的机械不再做任何解释。

韩智宇不自觉地把手微微攥起，
陆海装作满不在乎，目光却整个钉在那道缝上，
希昂在自己心里，时隔许久，
感到一种自哈兹兰之后未曾有过的、不同的紧张升起。

那不是躲藏一方的紧张。
是逼近一方的紧张。

而就在那一刻，
这古老层最深的内里，第一次，
一只真正去过外面又归来的手的时间，
开始触及希昂一行的眼前。
