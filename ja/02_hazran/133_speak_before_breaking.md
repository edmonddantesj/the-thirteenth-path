# 第百三十三話　崩れる前に

夜になると、
この古い層は昼よりもっと静かになった。

だがその静けさは休む方の静寂ではなかった。

音が減った分だけ、
堪えている気配がもっとよく聞こえる夜だった。

遠くでは金属が冷える音がとても小さく響き、
近い方では昼の間堪えていた呻きがもっと細く漏れ出し、
誰かは眠った振りをしていて、
誰かは本当に疲れ果てて倒れていた。

シオンは中間通路の方に立って、
古い板に記された配置と人々の顔をゆっくり照らし合わせた。

まだこの役割が自分のもののように馴染んではいなかった。

だがハズランから積み重なってきた感覚は、
馴染んでいなくても先に動くことは知っていた。

誰が平気な振りをしているか。
誰が今その場に座っているけれど、
実はもう少し経ったら崩れるか。
誰を一人にしてはいけないか。

そういうこと。

昼はみな堪える。
人が見ていればもっと堪える。

夜はその堪えがいちばん先に緩む時間だった。

シオンは最初の一巡を終えて、
すぐに一人の前で止まった。

ハズランから来た若い男だった。

昼は物資運搬の方に付いていて、
大きな声も出さず黙々と動いていた人だった。

だが今は壁に背を預けて、
目を閉じているのに体があまりに硬く固まっていた。

眠っている姿勢ではなかった。

堪えていて少し止まった姿勢だった。

シオンが低く呼びかけた。

「大丈夫か」

男は答えなかった。

だが肩がごくわずかに震えた。

シオンはそれを見てもっと近づきはしなかった。
代わりに同じ距離を保ったままもう一度言った。

「大丈夫じゃないなら今言わないと」

その言葉が落ちた後、
男はしばらく静かだった。

それから噛み殺すように言った。

「弟がここにいないの、
さっき数を数えたとき初めて分かった」

シオンは何も言わなかった。

男は目を閉じたまま付け加えた。

「昼はずっと隣にいると思ってたんだ」
「ずっと仕事を振られるから、
自分もただやっていただけで」

その言葉は恨みではなかった。
だからこそもっと痛かった。

人は動いていると、
しばらく騙される。
まだ終わっていないと。
まだ本当に失ったわけではないと。

だが夜は、
その嘘がいちばん先に壊れる時間でもあった。

シオンはしばらくその男のそばに立ってから、
とても低く言った。

「今夜は一人にしておけないな」

その言葉は慰めではなかった。
だが今必要なのは慰めよりも先に、
一人にしないことだった。

しばらくして、
シオンはその男のそばに水を置き、
近くの人間二人に合図を送った。

先に言わなければならない。

古い機械が言っていた言葉は、
思ったよりずっと実務的な文だった。

誰が崩れる寸前かを見たら、
次は必ず誰かに知らせなければならない。

一人で気づいたまま流してしまえば、
それは役割を果たしたことにはならない。

一人目はそうして過ぎた。

二人目はもっと早かった。

子どもたちのいる方で、
ハズランから来た女が同じ布をずっと畳んでは広げていた。

初めは単なる癖のように見えた。
だがシオンは三度目から、その手が震えていることに気づいた。

そして四度目に畳んだとき、
その女は自分の手をもう開けなくなった。

シオンはすぐそちらへ行った。

「今休まないと」

女はすぐに首を振った。

「子どもたちを寝かさないと」

「今はあんたが先に消える」

その言葉に、
女は初めてシオンを見た。

驚いた顔だった。

あの言葉を自分に直接言う人がいるとは思わなかったという顔。

シオンはその表情を見た瞬間、
この古い層で自分の持ち分がなぜ必要なのか分かった気がした。

ここはみな長く堪えてきた人たちだ。
だからこそかえって、
自分が崩れる時点をいちばん遅く認める。

誰かがそれを先に見て言わなければならない。

しばらくして、
その女の代わりに子どもたちのそばに別の人間が座り、
女はほとんど崩れるように壁際に座り込んだ。

その瞬間にようやく、
彼女の手から布が落ちた。

シオンはそれを見ながらとてもゆっくり息を吐いた。

夜がもっと深くなるにつれ、
この古い層のまた別の罅も見え始めた。

人間だけではなかった。
機械たちも同じだった。

古い機械の一体は明らかに移動中に関節が一度大きくずれたのに、
何も言わずに再び軸を合わせて動いた。

別の機械は信号整理の途中、
一瞬視界が暗くなったように止まってから
何事もなかったかのようにまた作業を続けた。

シオンはその光景を見ながら奇妙な疲労を感じた。

ここは人だけが堪える場所ではない。
機械も自分の故障を最後まで隠しながら堪える場所だ。

そしてそれが、
この共同体全体をもっと危うくしていた。

そのとき後ろから、
昼に初めて声をかけてきた人間の女が静かに近づいてきた。

彼女はシオンの視線の先を辿ってから、
古い機械を二体ちらりと見て低く言った。

「見えた？」

シオンが頷いた。

女は苦い顔で付け加えた。

「ここは機械たちも同じだよ」
「人だけが最後まで平気な振りをするんじゃない」

その言葉は不思議にも、
シオンを少しひんやりさせた。

昼にはこの古い層がセラキオンの上よりも嘘の少ない場所に感じられた。
だが夜になると、
その中にもまた別の種類の嘘が見えた。

完全な振りではなく、
まだ堪えられる振り。

その嘘はもっと善意で、
もっと痛ましく、
だからこそもっと遅く見破られる。

シオンは古い板の上にもう一つ印を残した。

人間二人、
機械一体。
そして暫定監視が必要な区域一つ。

印は小さかったが、
その瞬間からこの夜は単なる当直の時間ではなくなった。

これはこの古い層がどこからまた罅が入り始めるのか、
先に告げてくれる夜だった。

そしてシオンは初めて、
それを言わなければならない側に立っていた。
