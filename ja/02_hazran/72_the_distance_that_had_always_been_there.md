# 第七十二話　ずっとあったのに今ようやく見える距離

ルハイが先に立って歩いていた路地は、いつの間にか二手に分かれた。

一方はもっと明るく騒がしいほうだった。香料と水、薄い装身具、気の抜けた楽器の音が絡み合って、人をどんどん前へ引っぱっていった。もう一方はそれより暗かった。小さな灯りがまばらに掛かっているだけで、風に揺れる天幕の影が深かった。

ルハイは二つを交互に見てから、何でもないように言った。

「俺、あっちをもう一回りしてくる」

ソリンがすぐ訊いた。

「なんで一人で」

「二人のあいだに俺がいたら、目立ちすぎるだろ」
ルハイが言った。

シオンがぎくりとし、ソリンはすぐに目を細めた。

「正気か」

ルハイは笑った。

「違うならいいけど」
ルハイが後ろへ下がりながら言った。
「どうせ向こうの水売りの路地は、俺のほうが速い。一回りしたらまた合流する」

冗談めかした言い方だったが、逃げるように抜けたわけではなかった。むしろわざと軽く流して、自分が抜けたあとが気まずくならないようにした、というほうが近かった。

ソリンは舌打ちした。

「ああいうとこだけ気が回るんだから」

シオンはあえて返さなかった。

ルハイがいなくなると、路地の空気が本当に少し変わった。たいしたことでもないのに、さっきまでとは違う沈黙が生まれた。

シオンとソリンは並んで歩いた。

並んで歩くのは、もともと慣れていた。一緒に逃げたことも多いし、同じ港を通り、同じ人間を警戒したことも多かった。

だが今は、足音一つ、
襟が触れ合う距離一つ、
互いに何も言わない時間が、前よりはっきり感じられた。

慣れていたからいつも素通りしてきたものが、夕方の光の下ではかえって鮮やかになる気分。

ソリンが先に口を開いた。

「またあの顔、出てる」

シオンが横を見ずに訊いた。

「どんな顔」

「何か見えたら追いかけたくてたまらないのに、知らないふりしようとしてる顔」

シオンはその言葉に、ふっと吹き出しそうになった。

「そんな顔もあるのか」

「あんたにはある」
ソリンが言った。
「昔から」

昔から。

その短い言葉が、不思議と長く残った。

シオンはそこでようやく、ソリンを一度見た。

ソリンは前を向いて歩いていた。いつもの無関心な顔。だがその無関心さがかえって、どれほど長く自分の隣でこういう顔を全部見てきたのかを、よく物語っているようだった。

路地の片側に、薄い布を何重にも重ねて作った小さな店があった。風がかすめるたびに、布のあいだでガラス片と金属の糸がごく弱く揺れた。奥には手首に巻く薄い防熱紐、遮熱布の切れ端、水袋の覆い、そして一見使い道がなさそうなのに、長く持ち歩かれた跡のついた小さな飾り物が吊るされていた。

ソリンが一瞬、足を止めた。

シオンはそれが意外で、ソリンを見た。

「どうした」
シオンが訊いた。

「別に」
ソリンがいいかげんに答えた。
「こういうの、あんまり壊れないから」

口ではそう言ったが、シオンは、ソリンの目がただ品物の値だけを見ているのではないと感じた。

長くもつもの。なかなか切れないもの。手に長く残るもの。

ソリンはもともと、そういうものを人より早く見つける人間だった。

店の主人は座ったまま手を動かしていた。膝の上に紐の束を載せ、古いものから無事な部分だけを切り取って、新しい結び目でつなぎ合わせているところだった。指先は太く、爪は短かった。右手の人差し指の内側には、糸が通ったところが長く押されて白く固まっていた。

主人は二人をちらりと見ると、すぐに商売人らしい笑みを浮かべた。

「お二人で選ぶと長持ちしますよ」
主人が言った。
「この路地の品は、そういうほうによく合うんです」

シオンはすぐに顔を背け、ソリンはひどく冷ややかに答えた。

「誰にでもそういう口きかないで」

店の主人は少しもひるまなかった。

「誰にでもは言ってませんよ」
主人は平然と言った。
「こういうのは、目が先に教えてくれますからね」

シオンはその言葉がやけに引っかかって、なおさら口を閉ざした。

ソリンはしばらくその商人を見ていたが、かえって避けずに、店の中へもう一歩入った。

そして、いちばん飾り気のない形の薄い防熱紐を一本手に取った。光る飾りもなく、色もほとんど死んでいたが、結び目のところだけは妙に頑丈そうだった。

「これ、いくら」
ソリンが訊いた。

商人が値を言い、ソリンはすぐに鼻で笑った。

「泥棒だって、そこまで堂々とはやらないよ」

商人が笑った。

「分かってる手だ」

商人は値を少し下げた。それから紐を裏返して、結び目の内側を見せた。

「ここをご覧なさい。ハズランでどうして手首の紐が要るか、ご存じですか」

ソリンは答えなかった。商人は気にせず続けた。

「昼に金属を素手でつかむと、手が焼きつくんです。なら手袋をはめるでしょう。でも手袋をすると、指先の感覚が死ぬ。だからここの人間は、手は空けておいて、手首だけ巻くんです。熱は手首からいちばん速く入りますからね」

シオンはそれを聞いて、思わず自分の手首を見た。ハズランに入ってから、そこがずっとひりひりしていた理由が、いま説明された。

「だから、こういうのはきれいである必要がないんです」
商人が言った。
「一度切れたら、その日のうちに手首が焼けます。だからこの路地じゃ、いちばん売れなさそうな見た目のものが、いちばん売れるんですよ」

ソリンはそこでようやく、ごく短くうなずいた。それ以上、値を削りもしなかった。

シオンにはそれが少し意外だった。ソリンは値を削るとき、相手がどの線まで粘るかを正確に突く人間だ。それなのにいまは、突ける場所があるのに突かなかった。

ソリンはその紐を手に巻いてみてから、急にシオンのほうへ差し出した。

「あんたがつけな」

シオンがまばたきした。

「なんでおれが」

「あんた、いつも失くすじゃない」

あまりに当然のように言うので、シオンはすぐには言い返せなかった。

間違ってもいなかった。小さな道具、結束紐、薄いタグのようなものを、自分がよく落としがちだということを、ソリンは誰よりよく知っている。

シオンがしぶしぶ受け取ると、ソリンはどうでもいいことのように言った。

「それくらいは長く持ってな」

ただの品物の話のようだった。だがシオンには妙に、その言葉が品物にだけかかっているようには聞こえなかった。

商人は二人を交互に見てから、今度は何も言い添えなかった。代わりに膝の上の紐の束へ手を戻し、途中だった結び目を続けた。

シオンはその手をしばらく見た。太い指先が、糸を二度巻いて一度引く動きを、寸分違わぬ拍子で繰り返していた。今日売るものではなく、明日もその次の日も売るものを作る手だった。

シオンは紐を手首に巻いた。結び目は一度ではうまく作れなかった。二度目にようやくできた。

それから、ソリンの手首を見た。

何もついていなかった。

「お前は」
シオンが言った。

ソリンはこちらを見もせずに答えた。

「私が何」

「お前だって、手首焼けるだろ」

「私は失くさない」

「そういう話じゃないだろ」

ソリンはそこでようやくシオンを見た。表情は変わらなかったが、返事が一拍遅れた。

「一つの値段で二つ買ったら、それは値切りじゃなくて同情だよ」
ソリンが言った。
「あの人の手、見たでしょ。一日にいくつも作れない」

シオンは、その答えが本当の理由の半分くらいだと分かった。そして残りの半分は、訊いても出てこないだろうということも。

だから別の道から行った。商人のほうへ向き直って訊いた。

「さっきのあれ、切り落として残ったほうはどうするんですか」

商人が手を止めた。

「無事なところだけ使って、残りは捨てます」

「じゃあ、捨てる値段で譲ってください」

商人は少しのあいだシオンを見た。それから膝の上の束から短い切れ端を一つ選んで差し出した。色はすっかり死に、長さも足りず、手首にひと巻きすれば、どうにか結び目が作れるくらいのものだった。

「これは半年もちます。それ以上は保証できません」

「半年あれば十分です」

シオンはそれを受け取って、ソリンに差し出した。

ソリンはしばらくそれを見ていた。それから受け取った。

「安物だね」

「ああ」

「なら、いい」

ソリンはその場では巻かずに、ポケットにしまった。代わりにシオンの手首の結び目がゆるいのを見て、片手で端をつかみ、もう一度引いた。

「こうしないと、一日でほどける」

そして身をひるがえして、また路地の奥へ歩いていった。

シオンはしばらくその場に立っていた。

手首の薄い紐はたいしたものではなかった。高いものでもなく、珍しいものでもなく、なければすぐ困るような品でもなかった。

いや、一つは間違っている。なければ手首が焼けると、たったいま聞いたばかりだ。

そしてソリンのポケットには、半年もつものが一本入っていた。

不思議と、今夜のバザール全体より、その二本のほうが長く残りそうな気がした。

ずっとあったのに、今ようやく見える距離のように。
