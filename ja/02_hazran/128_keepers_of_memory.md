# 第百二十八話　記憶を抱える者たち

古い機械が現れた後、周りが静かになった。

誰かが沈黙を命じたわけではなかった。この空間に長くいた存在たちは、あの機械が話し出す前には自分から音を足さなかった。奥で湯を沸かす音だけがしていた。

古い機械はしばらく新たに入ってきた人々を見つめてから、ゆっくりと視線を動かした。

怪我人、老人、子ども、最後まで立っていようとする者たち。

立っていようとする者たちのひとりが、ハズランの年老いた男だった。壁から背を離して立っているあいだ膝が震えていたのに、男は座らなかった。

古い機械がまた言った。

「医療部品は潤沢ではありません。それでも、今必要な処置は優先します」

その言葉とともに、奥にいた別の機械が数体すぐに動いた。

大きな音を立てる機械はひとつもなく静かななか、一体の機械が箱をひとつ開けると布が出てきて、別の機械が水の器を運んだ。三体目の機械が怪我をした男の前に膝をついたが、膝から音がした。

怪我人は怪我人同士で壁際へ、子どもと老人は奥の温かいほうへ、歩ける者たちは箱を運ぶほうへ。

ルハイがそれを見てソリンを見たが、ソリンが首を振るのを見て口をつぐんだ。

ハズランの年老いた男は奥へ行くよう手振りで示されたが、行かずに壁に張りついて立ったままだった。機械はもう一度手振りをしない代わりに水の器を男の足元に置いて去り、男はしばらくしてからそれを手に取った。

同じ振り分けに見えたが、違うところがあった。上では機械が人の前に立って道を指したが、ここでは機械が箱を持って人のほうへ来た。人が動かなければ、機械が動いた。

ハン・ジウが見た、動いている機械たちの手は無骨だった。一体は指が四本で、別の一体は手首が逆に曲がっていた。部品が合わず、角度が違っていた。その手は布をつまもうとして二度取り落とし、三度目でつまんだ。つまんでから怪我をした男の脚の上に載せるときは、取り落とさなかった。

一人の子どもが治療用の布を見て怯え、大人の服の裾の後ろに隠れた。

奥の機械の一体が手を止め、とてもゆっくり子どもの目の高さまで膝を下げるあいだ、膝から音がした。

機械はなだめる言葉は言わず、自分の手を、手の甲が上になるように子どもの前に広げた。

傷のついた金属の手の甲、擦り減った関節、使い込んで色の褪せきった接続部。指の一本は先がなかった。

子どもはその手を見ると泣き止んだ。子どもの手が大人の服の裾から離れて機械の手の甲の近くまで行ったが、触れはしなかった。機械が手を動かさずにいると子どもは指一本で手の甲の傷に触れたが、そのあいだも機械はそのままだった。

「痛い？」

子どもが聞いた。

機械は答えず、手を裏返して手のひらを上に向けた。手のひらにも傷があって、子どもはその傷にも触れた。

大人が子どもの肩をつかんだ。引き寄せはしなかった。つかんでいるだけだった。

アカはその光景を見ながら小さく呟いた。

「こっちは隠さないんだね」

古い機械がその言葉を聞いたかどうかは分からなかった。しばらくして、最初に道を開けた機械がとても低く言った。

「隠すともっと怯えます」

ルハイがその言葉を聞いて小さく鼻で笑った。

「おかしなもんだな。まともじゃないほうが怖くないとは」

今度はハン・ジウが答えた。

「まともな振りをしないからね」

ルハイがハン・ジウを見たが、ハン・ジウは機械の手を見ていた。子どもはまだその手の甲に触れていた。

短い静寂が流れるあいだに、湯の沸く音が大きくなった。奥で誰かが器を置く音。

疲れた顔の女が水の器を持って出てきて、ハズランの子どもたちの前に先に置き、次に老人、次に怪我人たちの前に置いた。シオン一行の前には置かなかったが、ソリンはそれを見ても何も言わなかった。

女がソリンを見た。

「あんたたちは歩けるんだから」

「分かってる」

ソリンが答えた。

女はうなずくと、また奥へ入っていった。

しばらくして、古い機械はシオン一行の方へ再び視線を向けた。

「ここは長く堪える場所ではありません。記憶を受け渡し、次の失敗をもう少し小さくするために残っている場所に近いのです」

シオンはその言葉を声に出さずに反芻した。

アカが先に反応した。

「誰に？」

古い機械の光学眼がごくかすかに揺れ、不揃いな光がもう一度不揃いになった。

「まだ壊れていない方に」

アカは古い機械の首の下にある、三つの継ぎ当ての跡を見た。

ハン・ジウはその機械を長く見た。関節の規格の違う部品、不揃いな光学眼、三つの跡。彼女は自分の工具袋の上に手を置いて、また下ろした。

セルンが低く聞いた。

「あなた方がここを運営しているのですか」

古い機械はすぐに首を振ったが、首が回るのに時間がかかった。

「運営はしていません。維持しています」

セルンがその二つの言葉を記録板に並べて書くと、アテルがその記録板を見て、二つの言葉のあいだの間隔を見た。

「違いは何ですか」

アテルが聞いた。古い機械にだった。

「運営は増やします」

古い機械が答えた。

「維持は、減りを抑えます」

アテルはその言葉に一度うなずいた。

奥から人間二人が物資の箱を抱えて出てくると、別の機械二体が何も言わずにその重さを分け合った。人間が片端、機械がもう片端。箱が傾いた。機械の側が低かった。機械が腕を上げた。箱が平らになった。そのまま二人と二体で歩いた。

カエルはそれを見ていて箱を一つ持ちに行き、機械の一体が反対側をつかんだ。カエルが機械を見た。機械がカエルを見た。一緒に持ち上げた。箱が傾いたがカエルの側が高かったので、カエルが腕を下ろした。

ルハイがそれを見て自分も行ったが、持つ箱がなかった。手ぶらでしばらく立っていてから、また戻ってきた。

「全部持ってかれた」

彼が言った。

誰も笑わなかったが、ハン・ジウの口元だけが少し動いた。

ソリンがセルンの横に来た。

「出口二つのうち、どっちが上に行く」

「分かりません」

「聞け」

セルンが道を開けてくれた機械に聞くと、機械は暗いほうを指した。

「そちらが上へ行きます。明るいほうはさらに奥です」

ソリンが暗いほうを見た。

「塞いである？」

「塞ぎません。見ています」

ソリンがそれ以上聞かずにいるあいだに、アテルがその暗いほうの入り口へ行って立った。誰もそうしろとは言わなかった。

古い機械は最後にシオン一行を見ながら言った。

「問うのは後です。今は失われた数をまず数えなければなりません」

ハズランの年老いた男がその言葉に膝をついて座った。立っていた脚がもう持たなかったのだった。男は座って自分の指を広げた。さっき数えかけてやめた手だった。

古い機械は一歩踏むたびに膝を鳴らしながらその男の前へ行き、止まって膝を下げると、男と目の高さが同じになった。

男が顔を上げ、古い機械の不揃いな光学眼を見た。

「名前から言わなきゃいけませんか」

男が聞いた。

「いいえ。数からです。名前は後に残ります」

男が指を見た。
五。
もう片方の手。
十。
折って、開いた。

シオンはその指を見ながら、ポケットの金属板のことを思った。二本の線。彼は取り出さなかった。

奥から出てきた疲れた顔の女が手に持っていたのは薄い金属の板で、引っかいた跡でいっぱいだった。横に、縦に、斜めに。女はその板を古い機械の隣に置いた。男のすぐ前だった。

「ここに線を引きな。口で言うと忘れる」

女の爪が板の上の跡の一つを叩いた。

男がその板を見ると、板の上の跡は何百もあった。男は自分のポケットからドライバーを取り出した。ハン・ジウがくれたものだった。それから板の上にドライバーの先を当てた。

ハン・ジウはそれを見ながら自分の手を握った。

男が最初の線を引いた。ドライバーの先が金属を引っかく音がした。ハン・ジウが聞いたその音は、ハズランでシオンが金属板を引っかいていた音と同じだった。

男が二本目の線を引いた。

古い機械は膝を下げたまま、そのままでいた。立ち上がらず、線が増えていくあいだ、そこにいた。
