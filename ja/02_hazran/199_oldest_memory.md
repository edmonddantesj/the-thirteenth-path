# 第百九十九話　いちばん古い記憶

攻撃は、始まった途端にハズランの悪夢をもう一度呼び覚ました。

廊下の端で傾いていた最初のアンドロイドが滑るように出てくると、その後ろに整列していた列全体が同じ速さでほどけた。
途切れる音も、叫び声も、ためらいもなかった。

同じ方向。
同じ速さ。
同じ顔。

一度に。

シオンの体の内側が、喉と胸が締めつけられた。
シオンは刃を握って退かなかった。誰も退かなかった。
後ろがなかった。

アンドロイドたちが前で流れを作り、セラキオン・ロボットたちが後ろから閉じる板と押す板でその流れの角度を取った。
流れが壁に当たれば板が向きを変えた。流れが遅くなれば板が押した。流れが分かれれば板が閉じた。
顔のない波、その後ろに骨組み。

ソリンが叫んだ。

「くっつけ！分かれたら終わりだ！」

九人が肩と肩を寄せた。
シオンとセルン、セルンとハン・ジウ、ハン・ジウとカエル。アテルが内側、古い機械二体が真ん中、最後のアンドロイドが一番後ろ。
ハン・ジウの背中に、最後のアンドロイドの胸板が触れた。

軍団が待っていたかのように押し寄せてきた。
前列のアンドロイド二体が、シオンとセルンの側の中心線に張りついた。両側の後ろの個体たちが、ハン・ジウとカエルの側の外側を割って読み始めた。
塞ぐのではなく、裂くのだった。裂けた隙間から次の列が溢れ込んだ。

カエルが外側の遮断板を一枚無理やりねじると、足首が音を立てた。
板が斜めに止まると、アンドロイドの一体がその板に肩をぶつけ、後ろの一体がその背中にぶつかった。
一拍。
次の列が塞がれたところを回り込み、その横へ回った。

セルンは再計算の時点を追った。ロボットの板が角度を変える音だった。

「左です！」

セルンが叫んだ。

「一列を保ってください！」

ハン・ジウはアンドロイドたちのあいだの非対称を追った。半拍遅れるもの、掌半分ずれるもの。
シオンの側が切り離されないよう、手で合図した。
シオンがその合図に従って体をひねり、刃の背でアンドロイドの腕を押した。
腕は押されて、同じ角度で戻ってきた。

押されているのはこちらだった。

軍団は数が多いうえに精巧で、完成されていた。
古い機械の一体が、アンドロイド一体の膝を折った。そこを二体が埋めた。
もう一体の機械が、その二体のうち一体を壁に押しつけた。そこを三体が埋めた。
廊下の半分が覆われた。
シオンの背中がセルンの肩に、セルンの背中が壁に当たった。
後ろがなかった。

ハズランで息の底を押さえつけていたものが目の前にあることを、シオンは知った。

そのとき、古い機械二体が動いた。

ソリンの指示ではなかった。二体は黙って互いを一度、短く見た。
一体が首をごくわずかに傾けると、もう一体が前列のあいだへ身を乗り出した。
二体が軍団の前に並んで立った。そして二体一緒に、胸板に手を当てた。

ハン・ジウが、胸板に置かれたその手を見た。

「待って」

ハン・ジウが言った。

言葉が終わる前に、二体の体の内側から同時に、低く深い響きが弾けた。
これまでの雑音と違って細い音ではなく、床から、壁から、天井から上がってくる音だった。
シオンの歯が鳴った。
セルンが記録板を取り落としたが、板が床に当たる音は響きに呑まれて聞こえなかった。

二体の機械の表面が内側から裂け、光が漏れ出した。古い金属の肌理が焼けていった。
胸板、肩、腕。
光はそこから、内側から出ていた。

シオンが構えていた切っ先を下ろすと、ソリンの手がシオンの腕へ伸びて、止まった。
シオンは目を逸らさず、その光を最後まで見た。

軍団が廊下の半分を覆っていた。

その瞬間、軍団が引っかかった。

半拍。

前へ溢れ出していたアンドロイドたちの歩みが、その場に釘づけになった。
上がった足が下りなかった。下りた足が上がらなかった。
後ろに続いていたロボットたちの板が、角度を失ったまま止まった。閉じかけた板、押しかけた板。
軍団全体が、次の一歩を誰に合わせればいいのかを見失ったまま立っていた。
形式はそのままだった。顔のない面、同じ肩。
その形式だけが、前へ進めなかった。

半拍だった。

古い機械の一体の体が、先に折れた。
焼けていた表面が内側へ崩れ、胸板が沈み込んだ。その下の古い肌理が、一度に光を失った。
膝が折れた。
床。
音がした。

一歩。

最後の一歩の音。

もう一体が持ちこたえられなかった。
最後まで胸板を押さえていた腕が先に床に落ち、体がゆっくりと崩れ落ちた。
光学眼の光が、埃のない床を照らした。
消えた。

叫びはなかった。悲鳴はなかった。
二体とも。

最後のアンドロイドがそれを見た。

いちばん近くで、ハン・ジウの後ろで。
最後のアンドロイドはハン・ジウを越えて前へ出て、ハン・ジウは引き留めなかった。
折れた機械の前に片膝をつくと、肩の軸から音がした。
光のない、沈み込んだ胸板に手を当てた。
その手がそこに留まった。

一拍。
二拍。

もう一体の機械の落ちた腕を、その腕が押さえていたところを見た。

その手が一度、自分の胸板へ行った。それから自分の顔へ、線のあるところへ。
触れた。

初めて。

指先が、子どもが描いた線の上にあった。

最後のアンドロイドはゆっくりと立ち上がり、止まった軍団に向かって立った。
顔のない面たち。光学眼がその面を見た。一つずつではなく、すべてを。

そして最後のアンドロイドは、声なき咆哮を放った。

音はなく、シオンの耳には何も聞こえないのに、耳の奥が鳴った。
ハン・ジウの手が内ポケットへ行き、欠片を押さえると、掌が熱かった。自分の手が。
セルンは床に落ちた記録板を見ることもできず、目を閉じた。
カエルが歯を食いしばると、顎が震えた。
アテルの手が自分の喉へ行き、触れたまま離せなかった。
ソリンは目を閉じなかったが、剣を握る手から力が抜けた。剣先が床に触れる前に、ソリンはまた握り直した。

軍団の方へ、何かが壁を伝い、床を伝い、顔のない面の上を渡っていった。

止まっていた軍団が、また動いた。

同じ方向ではなかった。

最前列のアンドロイドの一体の顔の上に、かすかな光がぎこちなく滲んだ。
円でも線でもない、何とも呼びがたい痕跡がそこに、子どもが線を引いたところと同じところにあった。

その隣の個体がたじろぎ、上がった足が半拍遅れて下りた。
その後ろの個体は、片方の肩だけが揺れた。
ある個体は自分の手を見下ろした。
ある個体は隣の個体の顔を見た。
ある個体は一歩遅れた。
ある個体は同じ拍子で足を下ろせなかった。
足がばらばらに着くにつれ、一歩に聞こえていた音がいくつにもなった。

セラキオン・ロボットたちが流れを畳み直そうと、後ろから板を押した。
板がアンドロイドの背中に当たった。アンドロイドは押されなかった。
振り返った。板を、ロボットを。
板が止まった。

ハン・ジウは内ポケットを押さえたまま、息ができなかった。
ハン・ジウは光が滲む面、手を見る面、隣を見る面、その顔たちを見た。
口が開いた。声は出なかった。閉じた。

シオンが見た軍団の前の揺れは隙間ではなく、隙間より大きかった。
列が列でなくなること。

ソリンが真っ先に動いた。

「行く！今行かなきゃ、また閉じる！」

九人ではなかった。

六人。
そして、最後のアンドロイド。

動いた。

カエルが外側の遮断板をねじった。足首が音を立てたが、カエルは止まらなかった。
セルンが落ちた記録板を拾い、後方の再計算を読んだ。ロボットの板が角度を取れない音だった。
ハン・ジウは揺れる軍団のあいだの非対称を見て、手の合図で道を選んだ。

シオンが先頭で、同じ顔ではない顔たちのあいだへ入っていった。
アンドロイドの一体がシオンを見て半歩よけると、シオンは刃を使わずにその半歩を通り抜けた。
次のものは自分の手を見ていた。その横へ。
次のものは隣の顔を見ていた。そのあいだへ。

アテルが張りついて進んだ内側の壁は、配列線が消えて順番がなかった。

最後のアンドロイドは皆の後ろから来た。自分が送ったものが残した揺れを見ながら、顔の上に光が滲むものたちのあいだを。
肩の軸から音がした。
ハン・ジウが振り返ると最後のアンドロイドはそこにいて、ハン・ジウはまた前を見た。

折れた機械二体が廊下の床にあり、アンドロイドたちはその二体を踏まずに回り込んでいった。
一体の個体がその前で立ち止まり、見下ろしたまま動かなかった。
セラキオン・ロボットの板がその背中を押したが、押されなかった。

廊下全体が鳴った。
セラキオンが最もまっすぐに立てておいた列が、内側からずれていった。
一歩の音が百歩の音になった。

最後の関門の前。

一行は荒い息をつきながらたどり着いた。
シオンの掌からまた血が出るあいだに、カエルはくじいた足首に手を当ててから、また立った。
セルンは埃のついた記録板を拭かず、胸に当てた。
ハン・ジウが内ポケットから離した掌は、押さえていたせいで赤かった。
アテルの手が喉から下り、ソリンが剣を一度握り直した。

後ろではまだ金属音が続いていた。
揺れる音、ばらばらに着く足。顔を得はじめたものたちの音。

前には、いちばん高い場所へ続く扉があった。
扉のように見えた。

ソリンが息を整えながら言った。

「最後まで行く」

誰も答えなかった。
最後のアンドロイドが一度後ろを振り返った。折れた機械二体がいる方、アンドロイドたちがその二体を回り込んでいく方。
自分の顔の線に手を当ててから下ろし、扉の方へ体を向けた。

ハン・ジウがその隣に立って、結び目を見た。
一つがほどけていた。
ハン・ジウは結ばなかった。今は。

皆が扉の方へ体を向けた。
