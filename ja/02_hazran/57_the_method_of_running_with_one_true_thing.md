# 第五十七話　本物一つを持って逃げる方法

合流は終わりではなく、選択の始まりだった。

ハン・ジウのスキフとカエルの滑走機が同じ外縁の下の線へ降りて寄せると、四人は初めて、同じ問題を一緒に解かなければならなくなった。

どうやって生きて出るか。
どうやって本物の火種を手放さずにいるか。
どちらの機体が前を開き、
どちらの機体が後ろを断ち、
誰が手を空け、
誰が最後まで握り続けるのか。

シオンには、手の中の火種がやけに重く感じられた。

本物だということは確かめられた。
だからこそここからは、これを握っているという事実そのものが荷だった。速さより先に優先順位を変え、人の動きまで変えてしまう荷。

カエルが先に低く言った。

「寄るぞ」

それは感想ではなく、距離の報告だった。二機の間隔は、もうごく短くなっていた。あと少し寄せれば人ひとりを移すこともできるし、逆に寄せすぎれば一緒に引っかかって崩れることもある。

セルンがすぐに言った。

「いまは、完全には寄せないでください」

ハン・ジウが短く訊いた。

「理由」

「一度にまとめて食われやすくなります」
セルンが答えた。
「二機が別々に見えれば、追う手も割れます。ですが本物がどこにあるか確かになった瞬間、全部が一列に食いついてきます」

ハン・ジウは余計なことは言わず、前方の線に目を走らせた。

正しかった。

これまでは暗赤色の滑走機一機がいちばん近くに食いついていたが、競技場の外の手たちまで本格的に匂いを嗅ぎつけ始めれば、状況は変わる。二機が完全に一つの塊になった瞬間、守るべき標的もはっきりしてしまう。

カエルがシオンの手元を一度見て、訊いた。

「それ、別のところへ移すか？」

シオンはほとんど反射的に、いっそう強く握った。

「まだだめだ」

それより先に、セルンが低く付け加えた。

「移せば、揺れます」

その言葉は正確だった。
本物の火種は、華やかではなくても生きている。いま持ち手を替えるのはただ物を渡すことではなく、反応をもう一度揺さぶることになりかねない。ここで下手に判断を変えれば、偽物に騙されたチームと同じように、自分の手で本物を殺してしまうかもしれない。

ハン・ジウが短く結論を出した。

「なら、シオンが最後まで持つ」

カエルはすぐにうなずいた。

「了解」

短い合意だった。
それでもシオンには、その一言が妙に大きく聞こえた。自分の手に本物が残るということでもあり、それだけ標的もずっと自分のほうへ食いついてくるということでもあったから。

後方の暗赤色の滑走機は、また線を詰めてきていた。

今度は、最初のように試すような寄せ方ではなかった。前の操縦士はもう角度を下げきり、後ろの搭乗者は手を空けていた。奪うべきものが本物かどうか、もう確かめる必要がなくなった人間たちの動きだった。いまあのチームは、すでに確信している。火種はハン・ジウの組の手にある。

「確信したな」
シオンが低く言った。

セルンがすぐに受けた。

「だから、いま変えなければなりません」

ハン・ジウが眉をごくわずかに動かした。

「移さないって言ったろ」

「火種ではなく、線です」
セルンが言った。
「追われる側を変えなければなりません」

カエルが先に飲み込んだ。

「おれたちがもっと目立って引き受けるってことか」

「はい」
セルンが答えた。
「ハン・ジウの組は下の汚れた線へ抜け、私たちは上で一度大きく見せます。暗赤色のほうが二つのうち一つにしか食いつけない瞬間を作れば、火種を持つ手は捕まりにくくなります」

ハン・ジウはその言葉を聞いても笑わなかった。

代わりに、前方の外縁線と上のきれいな線、そしてそのあいだに残った死んだ骨組みの影を、もう一度見た。

「やれなくはない」
ハン・ジウが言った。
「でも、一度は本当に離れる」

カエルがひどく淡々と答えた。

「一緒に逃げるってのは、もともとそういうもんだ」

シオンには、その会話があまりに早く結論に行き着くのが、かえって奇妙だった。けれど、奇妙でもなかった。いまは四人とも、説明より生き残るほうに寄った頭で動いていた。

観覧台の上でも、その変化は読まれていた。

ルハイは、下で二機が一瞬寄ってからまた間隔を調整するのを見て、すぐに顔をしかめた。

「あいつら、いま何を組んでるんだ」

ソリンがごく低く言った。

「片方が囮になるんだろうね」

アテルがすぐに彼女を見た。

「どちらが、ですか」

「それはまだ分からない」
ソリンが答えた。
「でも、本物を持った手はだんだん見えないほうへ抜けていく」

その言葉は正しかった。
本物を握った手がいつまでもはっきり見えていれば、ハズラン全体が押し寄せる。
だからここから大事なのは速さより、**誰が本物を持っているのかを、一瞬でもぼかすこと**だった。

ナシムは下を見ながら、ごくわずかに口元を固くした。
彼ももう分かったはずだ。競技の板が壊れた以上、残るのは、本物を誰が持ってどこへ抜けるのか、それだけだということを。ハルンは相変わらず静かだった。ザヒルは最後まで動かなかった。だがその沈黙が長く続くほど、次の介入はかえって重く落ちてきそうに思えた。

アカは二機を交互に見ていた。

しばらくそうしてから、言った。

「いま、どっちも持ってるみたいに行ってる」

ソリンが顔を向けた。

「え？」

「あの二つ、どっちも持ってるみたいに行ってる」

アカが下を指さした。

「誰が持ってるか、わからないように」

ソリンは二機をもう一度見た。

ハン・ジウの組は火種を持っているのに、持っているそぶりを見せなかった。カエルの組は何も持っていないのに、包み込む角度で寄せて、持っているかのように動いていた。

さっき暗赤色の滑走機が、どちらに先に食いつくか一瞬迷ったのは、そのせいだった。

「わざとああしてるのか」

ソリンが低く言った。

アテルが答えた。

「そうであれば、いいのですが」

ソリンがアテルを見た。

「違ったら？」

「それなら、たまたま当たっただけです。偶然は、次には来ません」

アカはそのやりとりを聞いて、また下を見た。

「持ってれば、いい」

アカが言った。

「わざとでもそうじゃなくても、いまはあれで合ってる」

ちょうどそのとき、上から暗赤色の滑走機がさらに深く切り込み、角度を詰めてきた。

もう本当に、決めなければならなかった。

ハン・ジウが短く言った。

「いま決めろ」

セルンがすぐに答えた。

「私たちが上へ浮きます」

「浮いたら捕まるだろ」
カエルが言った。

「捕まるために浮くんです」

カエルはその言葉に一度息を止め、それから操向に手をかけた。

「どれくらい」

「あちらが私たちを先に見るまでです」

シオンはそのやりとりを半分ほど聞いた。通信が澄んでいなくて、言葉が途切れ途切れに届いた。

途切れて届いたのに、何を言っているのかは分かった。

上へ浮けば、よく見える。よく見えれば、追う側はまずそちらを見る。見ているあいだは、下を見ない。

カエルの組は、何も持っていないのに持っているかのように浮こうというのだった。

「それで食いつかれたら？」

シオンが訊いた。

ハン・ジウが前を見たまま答えた。

「食いつかれたら、そこからは本物なしで堪えるしかない」

「そんなこと、できるのか？」

「あの二人のほうが上手い」

ハン・ジウの声に笑いはなかった。上手いという言葉が、褒め言葉には聞こえなかった。あの二人は、ないものをあるふりをするのに慣れている、という意味に聞こえた。

シオンは上の線を見た。

カエルの滑走機が、本当に浮いた。さっきまで低く寄せていたのが、わざと高く上がり、上がりながら一度大きく機体をひねった。隠す動きではなく、見せる動きだった。

暗赤色の滑走機が、そちらへ角度を移した。

シオンは手の中のものを、もう一度握った。

ここにあった。あっちにはなかった。なのにいま、追う側はあっちを見ていた。

これが、うまくいく方法だった。そしてうまくいっているあいだ、あの上では、ないものを持っているふりをする二人が、ひとりで殴られているはずだった。

シオンは火種をさらに深く握ったまま、ハン・ジウの背中を見た。

ハン・ジウは前だけを見ていた。

良い道ではなく、
死んだ線、
汚れた線、
他人が捨てた線。

もともと、あの人がいちばんうまく使う道。

「よし」
ハン・ジウが低く言った。
「なら、こっちは見えないほうへ行く」

その言葉と同時に、二機が初めて、それぞれ違う意図を持って同時に分かれる構えを取った。

一方は本物を隠すために、もう一方は本物を握る手のように見せるために。

そしてシオンには分かった。

ここからは、
一緒に逃げる方法だけでなく、
一緒に欺く方法まで身につけなければならない。

シオンはそれが嫌だった。

嫌な理由を見つけるのに、少し時間がかかった。欺くのが悪いからではなかった。いま欺かなければ死ぬのだから、欺くのは正しかった。

嫌なのは、分け方だった。

本物を持つ側は見えないところへ行く。持たない側はよく見えるところへ行く。そうなれば、殴られるのは持たない側だ。

持っている者は殴られず、持っていない者が殴られる。

シオンは上をもう一度見た。カエルの滑走機はまだ高いところにいて、暗赤色の滑走機がその後ろに食いついていた。

あの上でいま殴られているのは、シオンが持っているもののせいだった。

「ハン・ジウ」

「何」

「あれ、いつ降りてくる」

ハン・ジウはすぐには答えなかった。

「こっちが先に入れば、降りてくる」

シオンはその言葉を受け止めて、前を見た。

なら、急ぐしかなかった。急ぐことだけが、あの上を降りてこさせる唯一の方法だった。

シオンは前を、いっそう強く読み始めた。
